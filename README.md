## astronomy.py

Soon to be a Python library to programmatically access https://astronomy.wiki/. It underlyingly uses the MediaWiki REST API, but makes things cleaner with classes and stuff.

MIT license, no AI used.

### Installation

```
pip install astronomy.py
```

This requires Python 3.10+ because I want to use `match` statements. There are no dependencies.
